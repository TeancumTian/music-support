# music-support

《音乐从零到作曲》（Music from Zero to Composing）iOS / iPadOS App 的支持页、隐私政策和使用条款，纯静态 HTML（无脚本、无统计），中英同页，由 GitHub Pages 发布在 https://teancum.me/music-support/ 。

App Store Connect 里的「技术支持网址」填 `https://teancum.me/music-support/`，「隐私政策网址」填 `https://teancum.me/music-support/privacy.html`。App 里「设置 → 关于」也链到这三页（`App/Core/Services/AppLinks.swift`）。改动数据处理方式、联系邮箱或收费方式时，三个页面要和 App 里的说明一起更新（隐私政策同时改生效日期）。App 源码在私有仓库 TeancumTian/音乐从零到作曲（本地 ~/dev/音乐从零到作曲）。
